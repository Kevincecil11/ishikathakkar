# Stax Living project banner

Use GitHub **Add file > Upload files**, then commit on **version-2**.
Upload one photo for a full-width banner, or two/three for a side-by-side collage. Any original filenames work. Files here override the default Stax post-detail images without appearing twice in the gallery.

Use your own work. The withdrawn Stax brand book must not be used.
